# Mini Projet Backend

Ce projet est une API REST construite avec Node.js, Express et MongoDB. Il permet l'authentification des utilisateurs, la gestion des utilisateurs et de leurs produits.

## Technologies utilisées

- Node.js (https://nodejs.org/)
- Express (https://expressjs.com/)
- MongoDB avec Mongoose (https://mongoosejs.com/)
- jsonwebtoken (https://www.npmjs.com/package/jsonwebtoken)
- bcryptjs pour le hachage des mots de passe (https://www.npmjs.com/package/bcryptjs)
- dotenv pour les variables d'environnement (https://www.npmjs.com/package/dotenv)
- nodemon *(développement)*
- multer
- multer-storage-cloudinary
- cloudinary
- helmet
